# POL-SEC-002 | Data Handling and Masking
Owner: Information Security | Version: v6.0 | Updated: May 2026

## Customer data
Customer personal data, including names, account numbers, card numbers, Aadhaar and PAN, may be accessed only on bank-approved systems and only for an assigned task. Never copy customer data to personal devices, personal email or messaging apps.

## Masking
Account numbers must be masked to show only the last 4 digits in emails, tickets, screenshots and reports. Card numbers show only the first 6 and last 4 digits. Aadhaar numbers show only the last 4 digits.

## Non-production environments
Production customer data must not be used in development, testing or UAT environments. Use masked or synthetic data generated by the approved test data tool.

## AI tools
Do not paste customer data, client code or internal documents into public AI tools. Use only the AI tools approved by Information Security, listed on the security intranet page. Report any accidental disclosure to the security desk within 1 hour.
